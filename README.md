# La Lente

Une tortue géante porte un village sur un désert de sel changé en miroir. On traverse une journée en faisant défiler, de l'aube aux étoiles.

Démonstration 3D (Three.js), à voir sur https://brooly-cmd.github.io/la-lente/

Ingrédients : modèles créés dans Blender ; matières Poly Haven (CC0) ; personnages et animations Quaternius (CC0) ; polices Gloock et Instrument Sans (OFL) ; Three.js et Lenis (MIT).
